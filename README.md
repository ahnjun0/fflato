# FFlato

<p align="center">
  <img src="icon128.png" alt="FFlato 아이콘" width="96">
</p>

부산대학교 PLATO LMS에서 **어디서든 확장 프로그램 아이콘을 눌러 바로 출결**할 수 있는 Chrome 확장 프로그램입니다.

PLATO 출결 페이지에 직접 들어갈 필요 없이, 브라우저 상단의 확장 프로그램 아이콘 클릭만으로 현재 진행 중인 출결 세션을 확인하고 인증번호를 입력하여 출석할 수 있습니다.

## 주요 기능

- **원클릭 출결** — 현재 활성화된 출결 세션을 자동으로 검색하고, 팝업에서 바로 인증번호를 입력하여 출석
- **정확한 남은 시간** — 마감 시각 기준 카운트다운. 팝업을 닫았다 열어도 어긋나지 않습니다
- **시도 횟수 표시** — 인증번호가 틀렸을 때 서버가 알려주는 시도 횟수를 함께 보여줍니다
- **다중 과목 지원** — 여러 과목의 출결이 동시에 열려 있어도 한 화면에서 처리
- **이미 출석한 차시 제외** — 출석을 마친 차시는 조회 대상에서 빠집니다
- **자가진단 페이지** — 스캔 과정과 PLATO 규약 점검을 확인할 수 있습니다

## 설치 방법

1. 이 저장소를 클론하거나 ZIP으로 다운로드합니다.
   ```bash
   git clone https://github.com/ahnjun0/fflato.git
   ```
2. 브라우저에서 확장 프로그램 관리 페이지를 엽니다 (`chrome://extensions`, Edge 는 `edge://extensions`, Whale 은 `whale://extensions`).
3. 우측 상단의 **개발자 모드**를 활성화합니다.
4. **압축해제된 확장 프로그램을 로드합니다** 버튼을 클릭합니다.
5. 다운로드한 폴더를 선택합니다.

## 사용 방법

1. [PLATO](https://plato.pusan.ac.kr)에 먼저 로그인합니다.
2. 브라우저 상단의 확장 프로그램 아이콘(✔)을 클릭합니다.
3. 현재 활성화된 출결 세션이 자동으로 표시됩니다.
4. 교수님이 안내한 **인증번호**를 입력하고 **출석** 버튼을 누릅니다.

## 프로젝트 구조

```
├── manifest.json          # Chrome Extension 매니페스트 (Manifest V3)
├── popup.html / popup.js  # 팝업 UI
├── debug.html / debug.js  # 자가진단 페이지
└── src/
    ├── config/            # 엔드포인트 · 셀렉터 (PLATO가 바뀌면 여기만 고칩니다)
    ├── core/              # 세션 · 과목 · 시간표 · 감지 · 제출 · 자가진단
    ├── app/               # 팝업과 debug 가 공유하는 흐름
    └── lib/               # DOM 파싱 · 동시성 제한 · 저장소
```

`docs/plato-api.md` 에 PLATO 통신 규약(실측)을, `docs/packaging.md` 에 동작 원칙과
배포 절차를 정리해 두었습니다.

## 개발

의존성이 없습니다. Node 만 있으면 됩니다.

```bash
./tests/run.sh        # 구문 검사 + 단위 테스트
./tools/package.sh    # 웹스토어 업로드용 zip
```

`debug.html` 은 자가진단 페이지입니다. PLATO 가 바뀌었을 때 어디가 깨졌는지
셀렉터·API 단위로 짚어 줍니다. 확장을 설치한 뒤 팝업 우측 상단 **Debug** 로
들어갈 수 있습니다.

## 동작 원리

1. Moodle 웹서비스로 수강 중인 과목 목록을 가져옵니다.
2. 수업 시간표를 한 번 받아 캐시합니다. 이때 출석부가 없는 강좌도 가려집니다.
3. 지금 수업 중인 과목부터 출결 페이지를 조회하고, 세션을 찾으면 멈춥니다.
   못 찾으면 나머지도 조회합니다 — 보강은 시간표에 없을 수 있기 때문입니다.
4. 세션을 찾으면 그 페이지에 박힌 제출 정보를 그대로 읽어 둡니다.
   파라미터 이름을 확장에 하드코딩하지 않으므로 PLATO 가 바뀌어도 잘 따라갑니다.
5. 사용자가 인증번호를 입력하면 그 정보로 출석 요청을 전송합니다.

### 서버에 부담을 주지 않기 위해

학교 서버를 쓰는 도구입니다. 안 해도 되는 요청은 하지 않습니다.

- **아이콘을 누를 때만** 동작합니다. 백그라운드 폴링은 없습니다.
- 시간표를 근거로 **볼 순서를 정하고 찾으면 멈춥니다.** 전 과목을 매번 훑던 것에
  비해 실측 81% 적게 요청합니다. 출석부가 없는 강좌(자율강좌)는 아예 조회하지 않습니다.
- 동시 요청은 2개까지로 제한합니다.
- 사용하지 않는 API 는 호출하지 않습니다.

## 요구 사항

- Chromium 계열 브라우저 (Chrome, Edge, Whale 등 — Manifest V3 지원 버전)
- PLATO 로그인 상태 유지
- 기기의 시간대는 상관없습니다. 수업 시각은 한국 시간으로 해석합니다.

## 권한

이 확장 프로그램은 `https://plato.pusan.ac.kr/*` 도메인 접근 권한과, 출석 기록을
기기 안에 저장하기 위한 `storage` 권한만 사용합니다. 저장한 내용은 브라우저 밖으로
나가지 않으며(동기화도 하지 않습니다), 그 외 어떠한 데이터도 수집하지 않습니다.
