# FFlato

부산대학교 PLATO LMS에서 **어디서든 확장 프로그램 아이콘을 눌러 바로 출결**할 수 있는 Chrome 확장 프로그램입니다.

PLATO 출결 페이지에 직접 들어갈 필요 없이, 브라우저 상단의 확장 프로그램 아이콘 클릭만으로 현재 진행 중인 출결 세션을 확인하고 인증번호를 입력하여 출석할 수 있습니다.

## 주요 기능

- **원클릭 출결** — 현재 활성화된 출결 세션을 자동으로 검색하고, 팝업에서 바로 인증번호를 입력하여 출석
- **실시간 남은 시간 표시** — 출결 마감까지 남은 시간을 실시간 카운트다운으로 표시
- **다중 과목 지원** — 동시에 여러 과목의 출결 세션이 활성화되어 있어도 한 화면에서 처리
- **이미 출석한 과목 자동 필터링** — 오늘 이미 출석 완료한 과목은 목록에서 자동으로 제외
- **디버그 페이지** — 출결 스캔 과정을 상세히 확인할 수 있는 디버그 페이지 제공

## 설치 방법

1. 이 저장소를 클론하거나 ZIP으로 다운로드합니다.
   ```bash
   git clone https://github.com/ahnjun0/plato-attendance-extension.git
   ```
2. Chrome 브라우저에서 `chrome://extensions` 페이지를 엽니다.
3. 우측 상단의 **개발자 모드**를 활성화합니다.
4. **압축해제된 확장 프로그램을 로드합니다** 버튼을 클릭합니다.
5. 다운로드한 폴더를 선택합니다.

## 사용 방법

1. [PLATO](https://plato.pusan.ac.kr)에 먼저 로그인합니다.
2. 브라우저 상단의 확장 프로그램 아이콘(✔)을 클릭합니다.
3. 현재 활성화된 출결 세션이 자동으로 표시됩니다.
4. 교수님이 안내한 **인증번호**를 입력하고 **출석** 버튼을 누릅니다.

## 프로젝트 구조

```
├── manifest.json      # Chrome Extension 매니페스트 (Manifest V3)
├── popup.html         # 팝업 UI
├── popup.js           # 팝업 동작 로직
├── plato-api.js       # PLATO API 통신 모듈
├── debug.html         # 디버그 페이지 UI
├── debug.js           # 디버그 페이지 로직
├── icon48.png         # 확장 프로그램 아이콘 (48x48)
└── icon128.png        # 확장 프로그램 아이콘 (128x128)
```

## 동작 원리

1. PLATO 메인페이지에서 수강 중인 교과 과목 목록을 가져옵니다.
2. 각 과목의 출결 페이지를 병렬로 조회하여 활성 출결 세션을 탐지합니다.
3. 이미 출석 완료한 과목은 출석 현황 페이지를 확인하여 자동으로 제외합니다.
4. 사용자가 인증번호를 입력하면 PLATO 서버에 출석 요청을 전송합니다.

## 요구 사항

- Google Chrome 브라우저
- PLATO 로그인 상태 유지

## 권한

이 확장 프로그램은 `https://plato.pusan.ac.kr/*` 도메인에 대한 접근 권한만 사용하며, 그 외 어떠한 데이터도 수집하지 않습니다.
